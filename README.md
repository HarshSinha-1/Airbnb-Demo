# Airbnb Clone

This is a full-stack Airbnb clone consolidated into a single monorepo for archival and deployment purposes.

## Repository Structure

- `frontend/`: The Next.js React frontend. This directory is deployed via Vercel.
- `backend/`: The FastAPI backend source code. 

## Deployment

**Frontend:**
The frontend is deployed on Vercel and built exclusively from the `frontend/` directory.

**Backend:**
The backend is deployed independently on an Azure VM and can be accessed at:
[https://20-2-88-158.sslip.io](https://20-2-88-158.sslip.io)
*(Note: The backend code here is for reference/archival only and is not redeployed from this repo.)*
